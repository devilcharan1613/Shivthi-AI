# Shivthi AI Android

Native Kotlin + Jetpack Compose starter.

Open this folder in Android Studio (Hedgehog or newer) and sync Gradle. Install Android SDK 35. A Gradle wrapper has not yet been checked in; Android Studio may prompt to configure Gradle or you can generate a wrapper from a local Gradle installation.

This is a UI shell only. API integration, offline caching, authentication, navigation, tests, signing, and release APK are not implemented yet.
